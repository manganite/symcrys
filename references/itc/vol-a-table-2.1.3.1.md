# ITA Table 2.1.3.1: lattice symmetry directions (three dimensions)

Source: _International Tables for Crystallography_, Vol. A, 6th edition (2016), Chapter 2.1 (Guide
to the use of the space-group tables), Table 2.1.3.1, printed p. 151. Transcribed in birss-app from
a screenshot provided by Thomas (2026-07-11); checked against the printed page in the chapter PDF
on 2026-11-09, overbars included. The 5th edition (2005) has the same table as Table 2.2.4.1,
printed p. 18.

Transcription conventions: a leading minus sign is an overbar. Directions in one brace set are
symmetry-equivalent; the first entry represents the set. The sequence primary, secondary,
tertiary is the sequence of positions in the Hermann–Mauguin symbol. The two-dimensional rows are
omitted.

| Lattice                          | Primary                    | Secondary                     | Tertiary                          |
|----------------------------------|----------------------------|-------------------------------|-----------------------------------|
| Triclinic                        | None                       |                               |                                   |
| Monoclinic (a)                   | [010] (unique axis b) / [001] (unique axis c) |            |                                   |
| Orthorhombic                     | [100]                      | [010]                         | [001]                             |
| Tetragonal                       | [001]                      | {[100], [010]}                | {[1-10], [110]}                   |
| Hexagonal                        | [001]                      | {[100], [010], [-1-10]}       | {[1-10], [120], [-2-10]}          |
| Rhombohedral (hexagonal axes)    | [001]                      | {[100], [010], [-1-10]}       |                                   |
| Rhombohedral (rhombohedral axes) | [111]                      | {[1-10], [01-1], [-101]}      |                                   |
| Cubic                            | {[100], [010], [001]}      | {[111], [1-1-1], [-11-1], [-1-11]} | {[1-10] [110], [01-1] [011], [-101] [101]} |

Printed footnote (dagger): for the full Hermann–Mauguin symbols see Sections 2.1.3.4 and 1.4.1.
