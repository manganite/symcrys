# ITA Table 2.1.3.1: lattice symmetry directions (two dimensions)

Source: _International Tables for Crystallography_, Vol. A, 6th edition (2016), Chapter 2.1 (Guide
to the use of the space-group tables), Table 2.1.3.1, printed p. 151. Transcribed on
2026-11-22, overbars included, as printed. The three-dimensional rows of the same table are in
`vol-a-table-2.1.3.1.md`.

Transcription conventions: a leading minus sign is an overbar. Directions in one brace set are
symmetry-equivalent; the first entry represents the set. The sequence primary, secondary,
tertiary is the sequence of positions in the Hermann–Mauguin symbol. The primary symmetry
direction of every two-dimensional lattice is printed as "Rotation point in plane" (one cell
spanning the four rows).

| Lattice     | Primary                 | Secondary              | Tertiary               |
|-------------|-------------------------|------------------------|------------------------|
| Oblique     | Rotation point in plane |                        |                        |
| Rectangular | Rotation point in plane | [10]                   | [01]                   |
| Square      | Rotation point in plane | {[10], [01]}           | {[1-1], [11]}          |
| Hexagonal   | Rotation point in plane | {[10], [01], [-1-1]}   | {[1-1], [12], [-2-1]}  |
