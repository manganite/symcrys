# ITC Vol. D Table 1.5.7.1: the forms of the matrix characterizing the piezomagnetic effect

Source: _International Tables for Crystallography_, Vol. D, 2nd edition (2013), Chapter 1.5 (A. S.
Borovik-Romanov, H. Grimmer, M. Kenzelmann, "Magnetic properties"), Table 1.5.7.1, printed p. 135,
with the conventions of § 1.5.7.1, printed p. 134. Transcribed 2026-11-20, primes and overbars as
printed, and compared cell by cell with the transcription in birss-app
(`docs/references/ITC-table-1.5.7.1-piezomagnetic.md`); the two differ in one symbol, the first
orientation of C2v(Cs), which the print gives as m′2′m.

The table lists 66 magnetic point groups in 16 blocks; the groups of a block share one matrix.

What the print fixes (§ 1.5.7.1, p. 134):

- Matrix notation, eq. (1.5.7.4): M_i = Λ_iα T_α, i = 1, 2, 3, α = 1 … 6, with T_1 = T_11, T_2 = T_22,
  T_3 = T_33, T_4 = T_23 = T_32, T_5 = T_31 = T_13, T_6 = T_12 = T_21, and Λ_iα = Λ_ijj for α = 1, 2, 3,
  Λ_i4 = 2Λ_i23, Λ_i5 = 2Λ_i31, Λ_i6 = 2Λ_i12.
- Cartesian axes: the form belongs to the orientation the Hermann–Mauguin symbol names. Monoclinic
  and orthorhombic: x, y, z along the first, second and third entry; the table prints the
  monoclinic groups with the unique axis y, the symbol with three entries after "=". Trigonal and
  hexagonal: z, x, y along the first, second and third entry. Tetragonal: z along the first entry,
  x and y along the second. Cubic: x, y, z along the first entry.
- Square brackets: other orientations of the same group with the same form of the matrix.

Transcription conventions: a leading minus sign for the overbar, an apostrophe for the prime. The
Schoenflies column is as printed, subscripts on the line; where the print puts several groups on a
line, each has its own row here. `L14` is Λ_14; a coefficient is written before it (`-2L22`).
