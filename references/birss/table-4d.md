printed p. 59. Transcribed in manganite/birss-tables (`table-4d.md`, vendored in birss-app as
`birss-tables/`); taken over unchanged.

Not checked against print again since the transcription (2026-06-16); the tests reproduce every
row from the operations of the 32 classes, which an error in the transcription would break.

Notation:
- Minus signs are literal minus signs in the table values (for example, `-xx`, `-xy`).
- Headers of the form `xz(2)` and `yz(2)` denote the two distinct unrestricted permutations of the indicated component: `xz, zx` and `yz, zy`.

Row labels (A2-U2) are the rank-2 (m=2) instances of the symbol classes `A_m`-`U_m`
assigned to each of the 32 point groups in Table 4a — see `table-4a.md` for the
point-group -> symbol-class lookup and the full rank-mapping explanation (m=0 -> Table
4b, m=2 -> this table, m=4 -> Table 4f).
