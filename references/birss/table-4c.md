# Birss Table 4c: tensor forms of rank 1

Source: R. R. Birss, _Symmetry and Magnetism_ (North-Holland, Amsterdam, 1966), Table 4c,
printed p. 58. Transcribed in manganite/birss-tables (`table-4c.md`, vendored in birss-app as
`birss-tables/`); taken over unchanged.

Not checked against print again since the transcription (2026-06-16); the tests reproduce every
row from the operations of the 32 classes, which an error in the transcription would break.

Notation:
- The headers `x`, `y`, and `z` denote single tensor components; this table does not use grouped permutation shorthand.

Row labels (A1-U1) are the rank-1 (n=1) instances of the symbol classes `A_n`-`U_n`
assigned to each of the 32 point groups in Table 4a — see `table-4a.md` for the
point-group -> symbol-class lookup and the full rank-mapping explanation (n=1 -> this
table, n=3 -> Table 4e).
